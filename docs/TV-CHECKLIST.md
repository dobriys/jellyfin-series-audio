# Проверка на Android TV 0.19.10

Проводить после установки на Jellyfin 12.4.0. Реальная проверка на телевизоре пока не отмечена выполненной.

- [ ] Выбрать озвучку, отличающуюся от первой русской дорожки, и сохранить её в браузере для тестового профиля.
- [ ] Запустить эпизод с начала на приставке. В меню аудио проверить именно студию, а не только язык. Зафиксировать, было ли короткое переключение после старта.
- [ ] Перейти на следующую серию автоматически, затем вручную. В обоих случаях проверить студию.
- [ ] Повторить на Android-телевизоре с тем же профилем.
- [ ] После начала просмотра вручную выбрать другую озвучку, подождать не менее 30 секунд. Плагин не должен переключать обратно. Этот ручной выбор пока не сохраняется на весь сериал.
- [ ] Открыть сериал другим пользователем: предпочтение первого пользователя не должно применяться. Администратор может явно сохранить отдельное предпочтение второму.
- [ ] Проверить эпизод без выбранной студии: воспроизведение работает с обычным выбором Jellyfin.
- [ ] Если есть серия с другим порядком дорожек — проверить сохранение студии. Если такой серии нет, этот сценарий уже покрыт синтетическими тестами, но не отмечать его как проверенный на реальном контенте.
- [ ] Повторить с прямым воспроизведением и транскодированием. Не считать наличие команды в журнале доказательством правильного звука.
- [ ] Перезапустить сервер, проверить сохранение настройки.
- [ ] Нажать «Использовать настройки Jellyfin», запустить эпизод снова, проверить возврат к обычному выбору.

Для отчёта достаточно: устройство, версия приложения, выбранная студия, фактически включённая студия, способ запуска (первая/следующая серия), наличие задержки и тип воспроизведения. Пароли и токены не нужны.
